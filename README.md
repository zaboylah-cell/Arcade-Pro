# 🎮 Arcade Pro

A neon-themed, responsive browser arcade with three playable mini-games.

## Play
Open **https://zaboylah-cell.github.io/Arcade-Pro/** after GitHub Pages finishes publishing.

## Games
- **Neon Dodge** — avoid falling blocks and survive for a high score.
- **Pixel Breaker** — bounce the ball and clear the brick wall.
- **Tap Rush** — hit the glowing target before the 20-second timer ends.

## Features
- Responsive layout for desktop and mobile
- Keyboard, pointer, and touch controls
- Personal bests, coins, and games-played stats saved with localStorage
- Synthesized sound effects with a mute toggle
- No frameworks, external dependencies, API keys, or paid services

## Run locally
Open `index.html` in a modern browser.
